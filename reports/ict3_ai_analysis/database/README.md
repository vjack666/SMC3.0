# Base de datos histórica — estado real

No existe archivo `.db`, `.sqlite` ni script `.sql` con datos históricos en esta copia del repositorio. El README del proyecto lo declara explícitamente: no hay volcado SQL local verificable, y se publica el dataset original disponible sin inventar una base distinta.

Por tanto `schema.sql` contiene únicamente documentación verificable, no un esquema de base de datos inventado. `data_inventory.json` recoge los recuentos reales de las fuentes que sí existen.
